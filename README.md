# watermelon_cat

UI 설계서 PPTX에서 슬라이드별 UI 정보를 뽑아 CSV / Excel로 바꿔 주는 추출기입니다.

## 설치

```bash
pip install -r requirements.txt
```

## 사용법

```bash
# 파일 하나
python ui_spec_extract.py 설계서.pptx

# 폴더 안의 pptx 전부 (결과는 한 벌로 합쳐짐)
python ui_spec_extract.py ./inbox -o ./out
```

`-o` 를 생략하면 현재 폴더 아래 `out/` 에 저장합니다.

## 산출물

| 파일 | 형태 | 용도 |
|---|---|---|
| `ui_list.csv` | UI 1개 = 1행 | 화면 목록, 진행 현황 관리 |
| `ui_flow.csv` | 흐름 항목 1개 = 1행 | 요구사항 추적, 테스트케이스 매핑 |
| `ui_element.csv` | 화면 구성요소 1개 = 1행 | 버튼·조회조건·데이터 항목 인벤토리 |
| `ui_spec.xlsx` | 위 셋 + 버튼 집계를 시트로 | 바로 열어 보는 용도 (필터·틀고정 적용됨) |

엑셀 시트는 `UI목록` / `UI흐름_상세` / `화면요소` / `버튼인벤토리` 네 장입니다.

### `ui_list.csv` 컬럼

`파일명`, `슬라이드`, `대분류`, `중분류`, `소분류`, `UI명`, `UI_ID`, `UI유형`,
`UI유형_원문`, `UI설명`, `화면정의`, `업무처리흐름`, `기타사항`

`UI유형` 은 원본의 `■화면  □팝업  □보고서` 에서 체크된 것만 골라
`화면` / `팝업` / `보고서` 로 정리한 값입니다.

### `ui_flow.csv` 컬럼

`파일명`, `슬라이드`, `UI_ID`, `UI명`, `섹션`, `순번`, `내용`

`UI 흐름 및 기타사항` 칸의 항목을 한 줄에 하나씩 펼친 것입니다.

### `ui_element.csv` 컬럼

`파일명`, `슬라이드`, `UI_ID`, `UI명`, `UI유형`, `영역`, `영역구분`, `순번`, `요소명`

`화면 정의` 의 `조회조건 영역 : 기준일, 사무소, 단위` 같은 한 줄을 요소 단위로
쪼갠 것입니다. `영역` 은 원본 표기 그대로이고, `영역구분` 은 이를
`버튼` / `조회조건` / `데이터` / `기타` 로 분류한 값입니다.
`영역구분` 이 `버튼` 인 행만 필터링하면 화면별 버튼 목록이 됩니다.

`전일(실적, 대비)` 처럼 괄호 안에 콤마가 있어도 쪼개지지 않습니다.

## 인식 대상 슬라이드

`UI 명` / `UI ID` / `UI 유형` 라벨을 가진 4행 6열 표가 있는 슬라이드만 처리하며,
표지·목차·EOD 슬라이드는 자동으로 건너뜁니다.

## 템플릿이 바뀌면

`ui_spec_extract.py` 상단의 `템플릿 매핑` 블록에서 도형 이름과 셀 위치만
고치면 됩니다. 라벨이 예상과 다르면 실행 중 `[경고]` 를 출력하므로,
조용히 엉뚱한 값이 들어가는 일은 없습니다.

자세한 구조 분석과 설계 결정은 `context-notes.md` 를 참고하세요.
